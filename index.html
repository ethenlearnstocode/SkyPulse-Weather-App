How to Install as a Web App

  1. Android (Chrome): Tap the 3-dot menu at the top right, then select "Add to Home screen" or "Install app".
  2. iOS / iPhone (Safari): Tap the Share button at the bottom of the screen, scroll down, and select "Add to Home Screen".
  3. Desktop (Chrome or Edge): Click the Install icon on the right side of the URL bar at the top.
  4. Hosting your own version: Save `index.html`, `manifest.json`, and `sw.js` into a GitHub repository and enable GitHub Pages under Settings to host it for free.
